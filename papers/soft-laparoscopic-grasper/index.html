TL;DR

A conference presentation on a soft laparoscopic grasper for small-intestine retraction.

Overview

This project page uses only public information from the prior portfolio and linked ResearchGate entry. The work is connected to the Boston University Morphable Biorobotics Laboratory laparoscopy project.

Key Contributions

  • Supported soft grasper actuator testing and mechanism prototyping.
  • Worked on soft force sensor and miniaturized actuator components described in the lab project page.
