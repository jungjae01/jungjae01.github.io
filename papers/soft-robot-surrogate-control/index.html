TL;DR

A soft-robot control paper connecting high-fidelity simulation and physics-based learning through a surrogate model.

Overview

This page summarizes only public information from Jungjae Lee's portfolio and the linked publisher entry. The prior portfolio states that Jungjae contributed to the Soft Robotics and Bionics Laboratory project through SOFA-based simulation setup, mesh optimization, and deformation simulation workflows.

Key Contributions

  • Supported soft robot simulation workflows for system identification.
  • Optimized simulation meshes to improve computational efficiency.
  • Evaluated and organized simulation tooling including SOFA, MuJoCo, and Gazebo.

Method Or System Overview

The public portfolio describes SOFA-based soft robot deformation simulation, pneumatic actuation replication, and mesh-density reduction work connected to the broader surrogate-model control study.
